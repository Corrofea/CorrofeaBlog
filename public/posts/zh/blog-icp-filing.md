# 个人博客备案踩坑记

> 2025.07.15 | 博客 · 运维 · 备案

## 为什么个人博客也要备案

在中国大陆，任何使用国内服务器且绑定域名的网站，都需要进行 ICP 备案。这包括你放在阿里云/腾讯云上的个人博客。

如果你用的是境外服务器，理论上不需要备案，但访问速度和稳定性会受影响。考虑到我的读者主要在国内，我还是决定老老实实走备案流程。

## 流程概述

整个备案流程大致分为三个阶段：

### 阶段一：服务商初审（1-3 天）

在云服务商的备案系统里提交材料：
- 身份证正反面
- 手持身份证照片
- 域名证书
- 网站备案信息真实性核验单

这里最容易踩的坑是**照片要求**。手持身份证的照片必须能清晰看到身份证上的文字，同时人脸不能有任何遮挡。建议在自然光下拍摄，不要开美颜。

### 阶段二：管局审核（7-20 个工作日）

服务商初审通过后，材料会被提交到省通信管理局。这个阶段只能等，没有任何办法加速。

管局审核期间，域名不能解析到服务器。也就是说你的网站在备案通过之前一直是 404 状态。

### 阶段三：公安备案（备案通过后 30 天内）

ICP 备案号下来之后，还需要去公安机关的网站备案平台做公安备案。这个步骤很多人会漏掉，但根据《计算机信息网络国际联网安全保护管理办法》，不做的后果可能是警告甚至罚款。

## 我踩到的坑

1. **域名实名认证**：备案之前，域名必须先完成实名认证。如果你用的是 `.com` 域名，实名认证通常在购买后立即生效；但 `.cn` 域名需要上传身份证审核，这个时间差可能让你多等一天。

2. **网站名称不能带"博客"以外的敏感词**：我第一次填"蚀羽 · 技术笔记"，被打了回来。个人备案的网站名称必须避开"论坛"、"社区"、"新闻"、"技术"等敏感词。最终我用了"蚀羽的个人空间"。

3. **备案期间不要动服务器配置**：管局审核过程中，如果你修改了服务器 IP 或者换了主机，备案会被退回重新初审。我就犯了这个错误——觉得无聊顺手迁移了服务器，结果从头再来。

4. **公安备案的"交互式服务"勾选**：如果你的博客有评论功能，在公安备案时必须勾选"交互式服务"。没有评论功能就选"非交互式"。个人博客强烈建议非交互式，减少审核复杂度。

## 时间线

```
Day  1 : 提交服务商初审
Day  3 : 初审通过，提交管局
Day 14 : 管局审核通过，获得 ICP 备案号
Day 16 : 完成公安备案
```

总共用了大约两周半，比预想的快。

## 拿到备案号之后

备案通过后，你需要在网站底部放置备案号，并链接到工信部备案查询网站：

```html
<a href="https://beian.miit.gov.cn/" target="_blank" rel="noopener">
  粤ICP备XXXXXXXX号
</a>
```

以及公安备案的图标和编号。这些是强制要求，缺一不可。
